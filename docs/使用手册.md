## 1. 关于 Reticle

### 1.1 它是什么

Reticle 给 AI 助手配一双手和一双眼睛。
助手用它看屏 读界面 点按 输入 跑命令。
它自己不思考 也不做决定。

它只接能自填地址的客户端。
目前适配 RikkaHub。
豆包 Kimi DeepSeek 这类封闭客户端接不上。

它在本机跑一个 MCP 服务。
向助手提供 28 个工具。
每一步都由你在对话里发起。

### 1.2 使用前须知

| # | 事项 |
|---|---|
| 1 | 需要 Android 11 或更高版本 |
| 2 | 首次使用完成三项授权 |
| 3 | 在 RikkaHub 里新增一条 MCP 记录 |
| 4 | 工具变更后重进客户端或开新会话 |
| 5 | 不暴露控件的应用只能截图识字 较慢 |
| 6 | 屏幕内容会发给你选的模型 |
| 7 | 从最近任务划掉 Reticle 功能全停 |
| 8 | 显示在册未连接时点修一次 |
| 9 | 连接异常先重进客户端再跑自检 |

## 2. 开始之前 三项权限

| 权限 | 能力 | 缺了会怎样 |
|---|---|---|
| 无障碍服务 | 看界面 触控 截屏 识字 | 完全不可用 |
| Shizuku | 以 shell 身份跑命令 | 命令不可用 |
| 所有文件访问 | 读写工作目录 | 命令与保存静默失败 |

三项都是标准授权 可随时在系统设置关。
关掉后对应能力立即失效。

### 2.1 Shizuku

Shizuku 是第三方权限桥接工具。
它借的只是 shell 身份 不是 root。
读不到别人的私有数据 也杀不了别人的进程。
改不了受保护的系统设置。

### 2.2 无障碍服务

这是核心权限 开放三件事。
读控件 截画面 注入手势。

在册与接上是两件事。
在册 名字还在名单里。
接上 系统真的连上了。
进程被杀后常出现在册没接上。
界面看着正常 功能已不可用。

| 显示 | 含义 | 处理 |
|---|---|---|
| 已连接 | 在册且接上 | 正常 |
| 在册未连接 | 系统没接上 | 等十几秒再点修一次 |
| 不在册 | 被系统摘掉 | 看门狗会写回 |

部分国产系统会定期关闭第三方无障碍。
看门狗约十秒写回 只写自己那一条。
不影响别的辅助服务。
写回次数记在状态页 多属正常。

修一次是删掉再写回 逼系统重连。

开机自动恢复默认关闭。
打开后开机写回无障碍并拉起后台。
它要 Shizuku 配合 部分系统还要放行自启。

### 2.3 所有文件访问

只为一件事 工作文件存在自己的目录。
Android 默认不许访问共享存储 要手动授予一次。
没有这项权限 命令与保存会静默失败。

### 2.4 何时重新授权

换手机或重装系统 三项都要重开。
手动关掉某项后 顶部状态卡会实时显示。
点卡片可刷新。
进程被杀后可能出现在册未连接。
处理见 2.2 与 8.3。

## 3. 连接 AI 助手

AI 客户端指 RikkaHub。
官网 rikka-ai.com。

### 3.1 工作原理

MCP 是助手连接外部工具的协议。
Reticle 在本机跑 MCP 服务。
把 28 个工具交给 RikkaHub。

服务只在手机内部跑。
同一 Wi-Fi 的其他设备连不上。
每次调用都要带令牌。
令牌对不上 请求不被处理。

地址 令牌 请求头名称在配置页管理。
见 7.3。

### 3.2 取地址与令牌

配置页的连接区有四个按钮。

- 复制链接地址 填进服务器地址
- 复制请求头名称 默认 Authorization
- 复制请求头值 已含 Bearer 前缀
- 复制 RikkaHub 官网 客户端下载页

地址与令牌随设备而变 以页面显示为准。
换端口即换地址 重生成令牌即换通行证。
RikkaHub 里要跟着改。

### 3.3 添加记录

打开 RikkaHub 的 MCP 服务器设置 新增一条。
地址粘贴复制链接地址的内容。
类型选 Streamable HTTP。
名称与值粘贴另外两个按钮 保存即用。

### 3.4 工具变更后重进

RikkaHub 在会话建立时拍一次工具快照。
Reticle 改了工具 当前会话看不到。
这是客户端机制 不是故障。
退出重进或开新会话即可。

## 4. 功能总览

Reticle 提供 28 个工具 分七类。

动作类工具可带两个条件。
`expect` 是动作后屏幕应出现的文字。
`expect_pkg` 是前台应用包名。
条件不满足 这次算没做成。
返回 `ok:0` 与原因。

常见失败原因
`not_found` 没找到目标
`expect_timeout` 动了但画面没变
`pkg_mismatch` 前台不是指定应用
`write_failed` 结果写盘失败

### 4.1 查看 6 个

| 工具 | 说明 |
|---|---|
| 截屏 | 截当前屏幕 游戏画面也能截 |
| 读界面 | 读控件树 含文字与位置 |
| 认字 | 离线中文识别 模型随包 可指区域 |
| 整屏文字 | 读整屏文字行与坐标 |
| 读剪贴板 | 只读 返回文字与长度 |
| 看窗口 | 列出可见窗口 标出聚焦那个 |

### 4.2 触控 7 个

| 工具 | 说明 |
|---|---|
| 点按 | 坐标取 0 至 1 的比例 |
| 按文字点 | 按文字或 ID 找目标 再点 |
| 长按 | 在指定位置按住指定毫秒 |
| 滑动 | 从一点滑到另一点 |
| 按键 | 返回 主页 最近任务 通知栏 |
| 滚动 | 滚一屏 避开手势区与返回区 |
| 滚着找 | 逐屏滚找目标 可顺手点它 |

点按 长按 滑动 按键 都可带前台校验。
前台不是指定应用 工具当场不动。

### 4.3 输入与等待 4 个

| 工具 | 说明 |
|---|---|
| 输入文字 | 向聚焦输入框写字 写完读回 |
| 粘贴 | 写剪贴板再粘 治不兼容输入的应用 |
| 等文字 | 等指定文字出现或消失 |
| 等画面稳 | 等页面不再变化 |

### 4.4 批量 1 个

一次提交多步 在设备端连续执行。
每步都能带两个条件。
不满足当场停下 回报停在第几步。
任一步失败 整批算没做成。
界面可预期时用 会变的界面改用单步。

### 4.5 系统任务 4 个

| 工具 | 说明 |
|---|---|
| 执行命令 | 以 shell 身份跑一条 限 30 秒 |
| 更新应用 | 在本机装新版 需手动确认 |
| 下载文件 | 按地址下载 给了校验值就核对 |
| 查下载进度 | 报进度 速度 大小 路径 |

下载只许写入 Reticle 下载目录或系统下载目录。

### 4.6 提醒与通知 2 个

| 工具 | 说明 |
|---|---|
| 震动提醒 | 震一下 不发声 不亮屏 |
| 发送通知 | 发 改 清通知 可写常驻正文 |

状态只用一条常驻通知 静默不振动。
折叠显示最近一次工具与结果。
展开可见最近几次记录。
通知里有隐藏守护按钮 点了只隐藏通知。

无障碍掉线时另发一条提醒 与常驻分开。

### 4.7 状态与自检 4 个

| 工具 | 说明 |
|---|---|
| 回铃 | 回一句确认 验证服务在线 |
| 状态报告 | 报版本 无障碍 Shizuku 内存 前台 |
| 工具目录 | 列必读事项与工具目录 |
| 动作自测 | 依次试点击 输入 滑动 返回 |

## 5. 白条与气泡

Reticle 在屏幕边缘显示一个白条。
工具调用与汇报通过气泡呈现。

### 5.1 两种形态

常规形态显示形象 贴边待命。
极简形态不显示形象 只留白条与气泡。
极简下白条常驻 气泡由白条展开生成。
收起后白条恢复原状。

### 5.2 开启极简模式

配置页 屏幕上的小形象 极简模式开关。
打开后形象专属项不再显示。
只留白条与气泡那一套。
改完立即生效 重开应用仍在。
两种形态共用同一套手势与让位规则。

### 5.3 白条手势

| 手势 | 结果 |
|---|---|
| 点一下 | 弹一下 气泡开着就收起 |
| 向屏内滑 | 拉出最近一条气泡 |
| 长按 | 白条被挤压 松开回弹 |
| 长按后拖 | 移动白条 松手贴回最近的边 |

点白条收起气泡后 静默一分钟。
拖动越过判定线才换边 线在 40% 处。
拖动带阻尼 越近边缘越慢。

### 5.4 气泡内容

第一行是图标与中文功能名。
后面接一句摘要 中间用中点隔开。
命令类只说功能 例如 `shell—读取文件`。
失败与超时在行末标注。
`notify` 显示消息原文 不加工。
两条消息间隔不到 1.5 秒时并列两行。
内容超高时 气泡内可上下滑动。

### 5.5 显示规则

- 工具调用 八秒
- 汇报 三十秒
- 失败与超时 六十秒
- 静默 点白条收起后一分钟不弹

让位名单内的应用在前台时不显示气泡。
失败也不显示 `notify` 除外。
在客户端里那一档 缩成细线。
点细条能出来五分钟。
静默期间普通气泡不弹 `notify` 与失败照常。

### 5.6 动效与外观

配置页 屏幕上的小形象 块内。

- 动效开关 关＝不做变形 直接出终态
- 手感 轻快 标准 柔和 三档单选
- 曲线 匀速 先快 先慢 过冲 四档单选
- 滑杆 动效时长 内容最大宽 内容最大高
- 白条 粗细 长度 圆角 透明度
- 气泡框透明度 字跟着一起淡

极简下换手感或曲线会立刻播一遍。
底部有恢复默认 手感与全部参数一起还原。
播一遍是白条收放连播两个来回。

### 5.7 装完与退出

覆盖安装后自动恢复 约一秒内可用。
设置与已开的权限都保留。
从最近任务划掉 Reticle 功能彻底停止。
无障碍一并交还系统。
再次打开会重新接管 首次要几秒。

## 6. 已知限制

以下边界都经实测确认。

**读不到界面的应用。** 微信等应用不暴露控件树。
这类应用只能截屏识字 慢一步 也可能认错。
游戏画面为自绘 读不到控件。

**独立窗口。** 权限框 输入法候选窗 系统弹窗都是独立窗口。
读不到内容 只能知道有窗口遮挡。

**只读一个窗口。** 分屏 小窗 多任务下只读聚焦窗口。
要操作别的窗口 先点它一下。
比例坐标按整屏算 多窗口下精度不受影响。

**剪贴板半开。** Reticle 能写入并粘贴。
读剪贴板只拿当前内容。
Android 10 起后台读取受限 读不到会明说。

**权限边界。** 命令身份是 shell 不是 root。
读不到别人的私有数据 杀不了别人的进程。
改不了受保护的系统设置。

| 限制项 | 说明 |
|---|---|
| 命令超时 | 单条 30 秒 超时终止 |
| 截屏节流 | 约每 350 毫秒一张 |
| 文字识别 | 特大号数字可能认不出 报错不猜 |
| 图像匹配 | 含动态内容的图样必然失配 |

**没有敏感内容拦截。** 不认也不拦支付页与密码框。
这类识别不可靠 也跟不上应用更新。

**应用无声。** 提醒只有震动与通知。

## 7. 隐私与数据安全

### 7.1 核心原则

屏幕内容会发到你在 RikkaHub 里选的模型。
Reticle 能看什么 就等于你愿让模型看什么。

### 7.2 数据流向

Reticle 不上传屏幕内容到任何外部服务器。
截图与界面信息只交给发起调用的助手。
之后是否出网 取决于你选的模型与线路。

主动联网只有两处。
下载文件按给定地址取文件。
检查更新向 GitHub 发布页发一次匿名请求。

检查更新每次打开应用问一次 至少隔十分钟。
直连不通时自动换中转站 界面上提示一句。
请求不带设备信息 账号 令牌。
可在配置页更新区关闭。
除此之外不联网 也无后台定时上报。

### 7.3 令牌与地址

令牌是访问 Reticle 的通行证。
拿到令牌又能访问本机地址的人 能看屏点屏跑命令。
不要把令牌贴到聊天群 截图或公开的地方。

怀疑泄露时 打开配置页的令牌与地址。
点重新生成令牌 旧令牌立即作废。
回 RikkaHub 重粘请求头的值。

同一区还能改请求头名称 换端口出新地址。
改端口后要同步改 RikkaHub 的地址并重启它。

令牌只存在 Reticle 私有存储里。
别的应用读不到 也不进通知与日志。

### 7.4 审计日志

每次调用记一行。
时间 工具名 参数摘要 结果 耗时。
参数超 120 字符时截断 令牌不入日志。
日志在工作目录的 `logs/` 按日期分文件。
单文件约 1 MB 后轮换 可查看或删除。

### 7.5 文件存储

截图与下载文件都存在 Reticle 工作目录。
该目录已标记为不进相册。

## 8. 故障排除

### 8.1 第一步 看运行状态

顶部卡片显示四项。
MCP 服务 无障碍 Shizuku 内存档位。
无障碍分开报在册与连接。
哪项异常 问题多半在那里 点卡片可刷新。

### 8.2 助手连不上

1. 重进 RikkaHub 见 3.4
2. 跑一次自检
3. 确认 MCP 服务在运行
4. 打开高级页的诊断 看日志末尾

### 8.3 无障碍被关或显示在册未连接

不在册时 看门狗约十秒内写回。
次数记在状态页。
显示在册未连接时 先等十几秒。
不回来就点修一次。
仍不行 到系统设置关掉再打开 或重启手机。

想手动催一次 用配置页的立即检查一次。
看门狗只改 Reticle 自己那一条。
不影响别的辅助服务 也可以完全关闭。

### 8.4 进程被杀之后

Reticle 不自行重启。
被回收后要重新打开。
从最近任务划掉后功能彻底停止。
无障碍一并交还系统。
重新打开即可接管 首次要几秒。

### 8.5 内存紧张时的降级

缓 看门狗从十秒放慢到六十秒。
收 释放缓存 例如文字识别模型。
让 极度紧张超一分钟 只留最小保活。

内存宽裕后自动升回。
条件是可用超过 12% 并持续 30 秒。
当前档位显示在配置页的内存行。
它不重启自己 也不反复重试。

### 8.6 重新初始化与彻底停止

重跑引导 配置页 引导 重跑一遍引导。
彻底停止 配置页 维护 停止所有功能初始化。
它会关看门狗 停后台服务与常驻通知。
下次打开会重新走引导。
系统无障碍开关不受控 要去设置里关。

### 8.7 应用更新

打开 Reticle 时检查一次 至少隔十分钟。
有新版时弹窗 首页多一行发现新版本。
弹窗以复制 GitHub 下载地址为主。
应用内下载会先提示速度可能很慢。
嫌慢就复制链接自行前往 GitHub。
下载显示百分比 速度 与剩余时间。
断网会重试 从断点继续。
直连不通时自动换中转站。
下完核对完整性 不符则删除并提示。

随后交给系统安装器 装不装由你点确认。
覆盖安装约一到三分钟 服务短暂重启后恢复。
更新完建议重进一次 RikkaHub。

### 8.8 仍未解决

准备运行状态截图与审计日志。
日志在 `logs/` 下 按日期存放。
带上它们 排查会快很多。

## 9. 技术架构

### 9.1 系统组成

| 组件 | 职责 |
|---|---|
| 无障碍服务 | 读屏与操作 截屏 手势 识字 |
| 本机服务 | 只在本机跑 验令牌 分派 记日志 |
| 工具层 | 把能力封成 28 个标准工具 |
| 看门狗 | 盯无障碍 被关就写回 |
| 内存自保 | 紧张时三级降级 |
| 前台服务 | 维持核心组件运行 |
| 更新模块 | 检查 下载 与安装新版 |

打包用的工程默认放在 Reticle/工程。
可在 build.conf 里改到别的目录。

### 9.2 一次调用的链路

RikkaHub 发起请求 携带令牌。
本机服务校验令牌 查工具表 记审计。
工具层调用无障碍服务或 Shizuku。
结果沿原路返回 失败时说清原因。

### 9.3 几个关键取舍

**坐标** 一律用 0 至 1 的比例 与分辨率无关。
**点击** 优先走控件级。
应用自报的边界与真实渲染有差异。
凭截图量的坐标可能点偏。
只在没法定位控件时用坐标 点完再读界面确认。

**不自愈。** 自行重启不可靠 也容易与系统冲突。
保命靠看门狗与内存自保。
进程整个被杀后要重新打开应用。

**单一数据源。** 工具说明 帮助目录 应用内手册同源。
改一处 三处同步。

## 10. 常见问题

**为什么在部分应用里很慢**
这些应用不暴露界面结构 只能截屏识字。
多一步处理 也可能认错。

**费电吗**
空闲时几乎不耗电 只在收到调用时工作。
看门狗每十秒做一次轻量检查。
耗电的是助手连续执行任务时。

**能只开部分能力吗**
可以 从系统层面分别控制。
关无障碍 不能看也不能点。
关 Shizuku 能看能点 不能跑命令。
关文件访问 命令与保存静默失败。
应用内可单独关掉看门狗 自启 与后台服务。
不提供只看不点的开关 这是有意取舍。

**它会自己重启吗**
不会 被系统回收后要重新打开 见 8.4。

**状态页写着自动恢复 N 次要紧吗**
不要紧 那是看门狗在写回。
部分系统会定期关闭第三方无障碍。
