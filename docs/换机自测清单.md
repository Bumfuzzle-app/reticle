# 55 · D 换机自测清单（给别家机主，照抄即可）

装好 Reticle＋Shizuku（Shizuku 需先用「无线调试」或电脑启动服务）→ 打开 Reticle → 按引导把三步权限给全。下面是 **30 秒出结论** 的照抄版。

## 一、看状态卡（不必动手，5 项全绿就算"能用"）
| 项 | 绿灯的样子 | 红灯怎么办 |
|---|---|---|
| ① 本地服务 | 显示"已启动" | 点旁边「重启服务」；还不行看底部日志最后一行 |
| ② 无障碍 | "已连接" | 若是"在册但没接上"：点「修一次」；若是"不在册"：到系统设置里手动打开 Reticle 的无障碍（**在册≠能用**，以"已连接"为准） |
| ③ Shizuku | 带 ✓ | 打开 Shizuku 确认服务在跑，再回来点「请求授权」 |
| ④ 通知 | "已授权"（Android 13+ 才要求） | 去系统设置给 Reticle 开通知 |
| ⑤ 内存 | "正常｜…" | 不是"正常"＝手机会卡，Reticle 正在让路，属正常自保 |

## 二、跑一次自检（免 token）
在手机浏览器／电脑上开：`http://127.0.0.1:8770/selfcheck`
- 端口若在配置页改过，用你自己的端口。
- 看到 `"ok":1`、`pass 6/6`（外加 `tools=…` 一行列出工具名）＝通路全好。
- 逐项含义：`badtoken=401ok`（鉴权）／`init=ok`（MCP 握手）／`toollist=ok`／`tooldl=ok`／`callping=ok`／`callbuzz=ok`（只验通路，不真震）。

## 三、真跑一遍手眼（在 AI 客户端里让它做，或直接看工具回报）
1. `ping` → 回一句 hello。
2. `shot` → 能截到屏（★Android 11 以下截不了，属已知降级，见 `降级路径.md` C1）。
3. `ui` 或 `ocr` → 能读出当前屏幕上的字。
4. `tap`（点一个按钮）→ 屏幕真的动了；`swipe`、`longpress`、`input`（往输入框写字）逐条试。
5. `key back/home/recents` → 按键生效。
6. `download`（找个几 MB 的文件）→ 落到 `/sdcard/Reticle/dl` 或 `/sdcard/Download`。
7. `buzz` → 手机震一下。
8. `shell`（例：`id`）→ 能回 shell 身份；不行＝Shizuku 那条路没通。

- 结果请附三样：**机型／系统版本（设置→关于手机）**＋**状态卡那 5 行原文**＋**`/selfcheck` 那行原文**。
- 反馈渠道与"支持范围"见仓库 README（安全上报另有单独邮箱）。
